## 🛠️ Tecnologías Aplicadas

* **HTML5:** Estructuración semántica del panel y formularios.
* **CSS3:** Estilos visuales, paleta de colores institucional y diseño adaptativo (*Responsive Design*).
* **JavaScript (Vanilla):** Manipulación del DOM, registro dinámico de órdenes, filtro de búsqueda en tiempo real y cálculo de métricas.

---

## ⚙️ Funcionalidades del Sistema

1. **Panel de Métricas (Dashboard):** Contador dinámico de órdenes activas.
2. **Registro de Órdenes:** Formulario para agregar clientes, servicios y estados iniciales.
3. **Tabla de Pedidos:** Visualización con distintivos (*badges*) según el estado del trabajo (Pendiente, En Proceso, Completado).
4. **Buscador en Tiempo Real:** Filtrado de registros al escribir.
5. **Eliminación de Solicitudes:** Botón para remover filas de la tabla de forma instantánea.

1. Descarga y descomprime la carpeta `Kratos_Publicidad_Frontend`.
2. Haz doble clic en el archivo `index.html`.
3. El proyecto se abrirá en tu navegador web listo para interactuar.
